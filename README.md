# Yelam Lawoti — Photography

Independent photography portfolio site, built with Next.js (App Router) and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

Sample portfolio photography is sourced from Unsplash under the [Unsplash License](https://unsplash.com/license); credits are listed on the site itself.
